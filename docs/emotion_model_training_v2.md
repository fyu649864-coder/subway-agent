## 三、7 类标签

平静、焦虑、愤怒、悲伤、恐惧、烦躁、无助（label2id 按此顺序 0..6，详见 `models/emotion/metro_emotion_v2/label_map.json`）。

| 项目 | 内容 |
|------|------|
| 路径 | `models/pretrained/models/iic--nlp_bert_backbone_base_std/snapshots/master/` |

| 加载方式 | 完全离线（`HF_HUB_OFFLINE=1`、`TRANSFORMERS_OFFLINE=1`），未联网 |

| 参数 | 值 |
|------|-----|
| 设备 | CPU（本机无 CUDA） |
| 最大长度 | 64 |

| 最大 epoch | 5（实际跑满 5 轮） |

| 随机种子 | 42 |

## 六、训练过程（Validation 集）

> 观察：train_loss 从 1.47 迅速降到 0.27 后基本不再下降，val_loss 在 1.3~1.5 间波动且高于 train_loss，存在一定过拟合，但 val_f1_macro 仍逐步提升至 0.32。

## 十、对模型当前效果的评价

- **积极方面**：相比 v1 的 Macro-F1 0.075，本次 Macro-F1 0.425、Accuracy 0.667，且全部在严格无泄漏的独立测试集上测得，结果可信。「平静」类 F1 达 0.95，说明模型对中性/正面话语识别可靠。
- **不足方面**：
  1. **小类仍是瓶颈**：恐惧、无助在测试集各 1 条且全错，根源是原始种子极少（3 / 5 条），增强无法弥补独立样本多样性的不足。
  2. **类别间混淆**：焦虑/愤怒/悲伤、恐惧/焦虑、无助/烦躁边界模糊，57→7 归并后仍有重叠。
  3. **过拟合迹象**：train_loss 0.27 vs val_loss 1.5，模型对训练模板有一定记忆。
  4. **测试集偏小**（21 条），指标波动大，单次结果仅供参考。
- **结论**：该模型可作为**基线版本**用于后端 mock 替换前的联调验证，但若要投入可靠的细粒度情绪识别，仍需补充恐惧/无助/悲伤等类的真实独立样本，并可考虑 GPU 训练下的更强骨干（RoBERTa-wwm）与 dropout 正则。
- 按要求**未进行自动重训**，本次结果已完整保存。
