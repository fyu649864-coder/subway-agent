## 二、7 类情绪定义

| 类别 | 定义 |
|------|------|
| 平静 | 情绪平稳、中性，或低唤醒的正面状态（满意、认可、轻松、礼貌、理解、歉意、温和建议等） |
| 焦虑 | 对未来、未知、时间压力的担忧与困惑（着急、担心、紧张、疑惑、窘迫等） |
| 愤怒 | 对人或事的气愤、不满、反感（生气、恼火、抱怨、嘲讽、吐槽等） |
| 悲伤 | 失望、沮丧、委屈、懊悔类情绪 |
| 恐惧 | 恐慌、惊吓类情绪 |
| 烦躁 | 烦躁、身体不适、无语等低方向感的负面不适 |
| 无助 | 无奈、压抑、不便等无力改变处境的感受 |

> 注：原 57 类中无独立「快乐」类，高唤醒正面情绪（开心、激动等）与低唤醒正面情绪统一并入「平静」，表示「无负面困扰」。

## 五、数据增强方式（仅 train）

采用**模板化受控增强**，不用 LLM、不接 API：
1. **核心短语抽取**：从原句中提取情绪/评价核心片段（优先逗号后的评价分句）。
2. **句式模板**：20 种口语化句式框架（"X，真让人Y"、"碰上X，Y，太Z了"、"每次都这样：X，Y" 等），将核心短语嵌入不同句法位置。
3. **槽位填充池**：
   - 情境短语：覆盖**列车延误、线路/设备故障、早晚高峰拥挤、赶飞机、赶考试、末班车、换乘困难、站台等待、车厢异常、有人晕倒/特殊乘客、服务投诉、导向不清、安检排队、车厢异味/噪音、空调异常**等场景（按原句 `场景` 优先匹配，再辅以通用情境）。
   - 程度词（太/真/特别/超级…）、语气词（啦/啊/呀/呢…）、情绪词池（每类 8 个近义表达，如焦虑：着急/揪心/心里没底/七上八下…）。
4. **去重与多样性过滤**：
   - 全局文本精确去重；
   - 与原句相似度 > 0.78（字符级）则丢弃，避免「换几个词」式伪增强；
   - 与最近 30 条生成句相似度 > 0.88 则丢弃，避免批量高度雷同。
5. 每类 train 目标量：平静 511 / 愤怒 490 / 焦虑 480 / 烦躁 480 / 悲伤 400 / 无助 350 / 恐惧 250，按该类 train 原始 group 数均摊增强条数。

> 说明：受限于「不接入 LLM/API」的约束，增强为规则模板生成，语言自然度不及人工或大模型改写，但全部保持**场景合理、情绪标签一致、文本互不重复**，且不修改原始样本。

1. 本数据集**未使用**原 Excel 中 6067 条增强行，全部 2882 条增强均为按上述模板新生成。
